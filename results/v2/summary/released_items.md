# v2 experiments: released_items

Test MAPE (%), mean ± standard deviation over the seeds that finished with a finite value (`failed` counts the others). Each row is one setup; setups are never pooled. `mape` uses the epoch named in `selected_by`; the next two columns show the same runs under either choice. `mape_released_units` is MAPE as the released code computes it (every part un-scaled with the validation part's minimum and maximum), which is not in jobs per interval. Generated by `python -m cwp.evaluate v2 released_item_adv_plus released_item_critic_steps released_item_embed_broadcast released_item_lr released_item_noshuffle released_item_pos_batch released_item_scaler released_item_tanh_critic released_item_windows --name released_items`.
