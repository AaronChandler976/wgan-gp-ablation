# Against the more_data runs: critic_v2_more

Each row compares one configuration of one experiment with the `more_data` runs (paper settings) of the same configuration, paired by seed. Test MAPE (%) at the best validation epoch; `change_points` and `change_pct` are the experiment minus the reference runs (negative is better); `p_paired_t` is not corrected for the number of rows, and with 3 seeds only large differences can be told from noise. `not_finite` counts pairs left out because a run diverged. The rows of different experiments are different setups and are not pooled. Generated by `python -m cwp.analysis versus critic_v2_more --name critic_v2_more --reference more_data`.
