# Effects across datasets (reported runs)

Datasets, in the order of `per_dataset_pct`: azure_functions-5m, google-10m. `pooled_pct` is a random-effects average of the per-dataset effects (change in test MAPE, %, negative is better) with a 95% interval; it widens when the datasets disagree. `between_dataset_sd_pct` is the estimated spread of the true effect from dataset to dataset. `p_differs` tests whether the effect is the same on every dataset (the effect-by-dataset interaction): a small value means the effect depends on the workload. With few datasets the pooled interval is rough; read it together with the per-dataset values. Generated by `python -m cwp.analysis pooled`.
