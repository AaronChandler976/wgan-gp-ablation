# v2 experiments: more_data

Test MAPE (%), mean ± standard deviation over the seeds that finished with a finite value (`failed` counts the others). Each row is one setup; setups are never pooled. `mape` uses the epoch named in `selected_by`; the next two columns show the same runs under either choice. `mape_released_units` is MAPE as the released code computes it (every part un-scaled with the validation part's minimum and maximum), which is not in jobs per interval. Generated by `python -m cwp.evaluate v2 more_data --name more_data`.
